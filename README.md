# dsh-m

**Marketplace for [DeepSeek Harness (DSH)](https://github.com/deepseek-ai) plugins.**

`dsh-m` 会收录大量 DSH 插件的安装地址，作为 DSH 插件市场的名称注册与分发入口。
当前版本为**占位版本**（name reservation），真正的 marketplace 功能开发中。

## 安装

```bash
npm install dsh-m
```
