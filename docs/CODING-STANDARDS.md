## 测试锚纪律（构建产物的三条物理事实）

本仓库构建（`scripts/build.mjs`）有两个非默认设定，加上工作树的检出形态，衍生三类**确定性为假**的测试断言：

1. **`treeShaking: false`** —— 未调用的标识符同样进入 `lib/client.js`。
   ⇒ 禁止「bundle 中 grep 不到某标识符」类负向预言（未调用 ≠ 不在场）。
   差分/负向锚只用两种合法形态：**源结构锚**（grep `src/**`，如「解构 1 处 → 加调用点后 ≥2 处」）或 bundle 中 **ASCII 字面量**的在场/缺席。
2. **esbuild 默认 `charset=ascii`** —— bundle 内一切非 ASCII（i18n 中文、CSS 模板串内中文）转义为 `\uXXXX`（注释除外）。
   ⇒ **中文文案锚一律走源结构锚**；bundle 锚只允许 ASCII 字面量。
3. **工作树 CRLF 检出** —— 盘上源文件行尾为 `\r\n`。
   ⇒ **源串锚禁含 `\n` 转义**（多行锚在 CRLF 内容上恒不匹配 = 恒真/恒假皆错）；多行语义改用切片锚（`indexOf`/`slice` 边界）或单行计数锚。守卫：`tests/source-anchor-hygiene.test.mjs`；028 §4 第 3 项（两例实证）。

量化断言一律**出现次数语义**（`grep -o … | wc -l` 或 `str.split(锚).length - 1`），不用 `grep -c`（行数语义，随打包行合并漂移）。
测试源锚计数一律 **needle 全文出现次数**（`src.split(needle).length - 1`），不用行首锚定的 grep 行数语义（同上 CRLF/多键行漂移）。

## 客户端状态机约定

- 面板手势类逻辑（拖拽/resize/后续同类）一律拆 **DOM-free 纯逻辑模块**（`src/client/window-*.js`，ESM 具名导出，禁 `module.exports`）+ node:test 直测（契约锚 + 数学矩阵 + 存取语义三件套）。
- 面板接线逻辑（泵上下文装配、恢复对账编排、横幅判定）同上拆 DOM-free 模块（先例 `src/client/panel-ops.js`，ADR-0023）：判定/编排以纯函数导出直测，副作用（setState/notify/落盘）留在组件内的薄 effect 适配器。
- DOM/React 接线层不写行为级 node 单测、不引入 jsdom：组件文件具名导出、可被测试直接 require，首渲染由渲染冒烟（SSR renderToString）覆盖；bundle/源锚仅覆盖无缝可走的物理事实（ADR-0023 三桶政策：「有缝即接口测试，源锚只留给无缝可走的物理事实」）。手势纪律逐条镜像既有先例（ADR-0017/0021：rAF 帧内写、手势帧零 setState、释放收口、setPointerCapture、主键门卫、多指守卫、卸载清理）。
- resize 拖拽路径**零动画**：不给 width/height/grid/flex-wrap 挂任何 transition（跟手 1:1 优先于装饰）。

## 行为零变化承诺（每特性必填格）

改动既有组件时，计划与 ADR 必须写明「缺省态/无记忆态与旧版的一致性口径」——几何一致、样式一致、DOM 节点数是否变化要分别如实声明；验收时按口径核验，不虚报「逐像素一致」。

## 证据纪律（计划与红线里的事实断言）

计划、语义等价红线、CHANGELOG 中关于「现状如何」的陈述，写入时就要有当场证据；四条全部可由评审执行：

- **行为断言必实测**：描述某输入今日的实际流转（函数返回值、钳制/floor 发生在哪层），以最小 `node -e` 探针或现有测试输出为据；读码推断的运行时行为按未验证处理。（0.9.92 红线 #3 两次写错教训：clamp 钳制值、clampLimit 归因。）
- **引用测试锚先读**：声称「某套件钉住 X」之前读过该文件当前版本；按文件名或记忆猜的锚按虚报处理。（0.9.92 计划曾虚称 tools-summary 有 systemPrompt 锚。）
- **行号锚写入即复核**：行段锚写进计划那一刻 grep 过现场——早前会话的行号按过期处理；消费时符号锚优先。（两役评审共抓出行号漂移 4+ 次。）
- **永真判据防呆**：git-diff 类判据的对象被 .gitignore 排除时**恒空**（0.10.9 二轮 O-7 实证：lib/ 不入库 → 「重建后 git diff -- lib/ 为空」永真）——产物一致性核证用 md5/构建指纹对照，评审见到 diff 判据先查对象是否入库。（retro C3。）
- **搬移脚本不变量**：脚本搬移代码后，源文件 diff 必须只含「删除行 + 已知插入」——出现无对应搬运的删除 = 脚本边界 bug（0.10.9 T11 实证：闭合扫描把单行 const 块误判块尾、吞掉无关代码），先修脚本再继续，不做手工补救。（retro C4。）
- **锚普查产出以符号锚表达**：普查/盘点类工具与文档把「文件 + 唯一内容锚/标识符」作为第一表达，行号仅作时点参考注记——0.10.9 评审 O-2 实证（普查行号快照里一处类名笔误 `dsvm-/dshm-` 混入，符号锚表达可在写入时即被内容校验拦住）。（评审 S-2。）
- **退出码卫生**：测试输出经过过滤管道（grep/head/tail）时，Bash 启用 `set -o pipefail`，PowerShell 在过滤前保存 `$LASTEXITCODE`；以原测试进程退出码判定，过滤器有输出 ≠ 测试通过。（0.9.93 A1 红测试曾被管道掩盖后 commit。）
- **环境既有失败 vs 回归的判别用结构化工具**：本机套件带环境既有失败（know-how 028 清单）时，回归判别一律跑 `node scripts/test-baseline.mjs`（stash → 基线全量 → 失败按名对照 → pop，显式退出码），禁止手搓管道对照——手工 ritual 的管道尾吞退出码是已被踩过的坑（0.10.11 轮实证一次），工具化后判据从「记得检查」变成「跑脚本看二元结论」。（retro S2。）

## 评审检查单

- [ ] 新逻辑落 DOM-free 模块且有单测（TDD：失败测试先行）
- [ ] 新增锚符合上面三条物理事实；量化为出现次数语义
- [ ] **计划追溯**：逐条将验收项映射到改动文件、具体测试名和复现命令；计划要求「新增测试」时，diff 必须能指到对应测试且评审亲跑该命令；未覆盖项须明确解释，不能静默跳过。
- [ ] **关键源码接线锚**：若一个源码锚是关键行为接线的唯一自动防线，在隔离副本做一次单点变异（改坏条件/键/调用）确认锚红，恢复后确认绿；输出落盘留证。
- [ ] 新 describe 自带测试夹具与 helpers——不引用兄弟 describe 闭包（跨 describe 引用 = ReferenceError；0.10.x 轮三例实证）
- [ ] i18n：`lookup("key")` 直接量全部落字典（守卫 `tests/client-i18n.test.mjs`；0.10.4 裸键名 toast 教训）
- [ ] 计划/红线中的事实断言过了「证据纪律」四条（实测 / 先读 / 复核 / 退出码）
- [ ] 判据命令自证两件事再入计划：计数 0 的退出码语义（`grep -c` 计 0 = exit 1，不进 `&&` 链）；判据在基线跑过一遍（永真/永假自证）。（0.9.94 教训：两处 `&&` 链断裂 + A1 永假锚 `guardBlockedText ≥ 5`。）
- [ ] 机理/可达性叙事附调用点序证据：谁先谁后在现场追过，局部代码段推不出全流程可达性。（0.9.94 D9 教训：restore 恒先于 verify → 「误报缺失」不可达，危害链实为 restore 自造重复键。）
- [ ] 测试夹具声明「前置管线步骤副作用」存活前提：被断言对象须扛得住夹具前置步骤的冲刷（strip/remove/整文件重写）。（0.9.94 N1 教训：T2 预置键与坏包同名，strip 先摘则红绿判读翻车。）
- [ ] 「行为零变化承诺」有对照格且按口径验收
- [ ] i18n 中英同步；文案改动有源锚
- [ ] **改函数返回/输出形态必清点断言面**：加字段、改三态/枚举等形状变化，先 grep tests/ 中该函数的全部 `deepEqual`/快照断言并同步改写——全对象 deepEqual 比对自身可枚举键集合，新键不改写必炸（0.11.0 实录：batchUpgradeOrder 加 `unsupported` 炸 4 处；改写处逐一列入 commit message）。
- [ ] 计划外改动未夹带（diff 逐文件可归因）
