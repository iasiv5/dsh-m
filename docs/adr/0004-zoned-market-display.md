# 市场展示从合并混排改为分区制，修订 0.5.0 Q45

0.5.0 把社区清单叠进主清单混排展示（主清单置顶 + 社区按下载量降序 + 「只看主清单」chip 常驻），预设「策展优先」的排位能在 4,200+ 条里托住 22 条精选。实测 22 : 4,194 的量级差让混排两头不讨好：精选淹没在 ~85 页线性翻页里，社区被 27+ 枚混编 chips 平铺。owner 同时确认产品定位从「个人自用」升级为「面向大众发布」，浏览重心让位社区全量。0.7.0 起市场面板改为分区 tab：社区（默认落地）/ 精选（策展单页）/ 收藏（本地），各区独立状态实例；数据层 `mergeRegistries` 去重与 ADR-0003 架构不变，「合并」收敛为数据层语义。定稿全文见 DESIGN.md §2.6。

## Considered Options

- **维持混排 + 强化来源筛选**（来源筛选组精选/社区/全部）：保留 0.5.0 形态只加筛选器——量级差面前筛选是补丁，默认视图仍然失衡，「只看主清单」chip 的存在本身就是混排的症状。
- **社区流顶部「编辑精选」横滚区**：策展内容以横滚置顶——精选失去独立浏览设施（分类、verified、文案标准的展示价值），退化为一排推荐位。
- **分区制（采纳）**：两层数据各自拥有完整的浏览体验，tab 独立状态实例互不污染；社区区排除与主清单重复的条目（displaced），精选不在社区区重复出现。

## Consequences

- 「只看主清单」chip、Q40 的 ui/tools/market 共享过滤桶退役；精选分类与社区分类彻底解耦（各区 chips 独立），「分类保留原生值不转译」不变。
- 「合并市场」术语收敛为数据层概念：主清单恒优先的去重合并仍然发生（安装解析、已装标注消费它），但展示层按社区区/精选区呈现；社区区不展示 displaced 条目。
- `dshm_search` 的 `primary_only` 删除，改为 `source` 三值参数与 GUI 分区对齐——「三端同源同语义」在分区制下重新成立。
- Q44 能力披露的载体从卡片折叠区改为详情 Modal（默认收起不变）；卡片瘦身为浏览密度让路。
- 精选区降为第二 tab：策展层的价值主张从「默认视野」变为「可信精选入口」，verified 与收录文案标准成为该分区的差异化内容。

## 修订（2026-10-02，0.9.16）

- 精选区分类法从功能五分类（market/tools/ui/search/other）改为**策展五桶**：装机必备（essentials）/ 崔添翼精选（cui-picks）/ 我的自研（self-dev）/ 腾讯轻量云专区（tencent-lighthouse）/ 观察区（watchlist）——分类语义从「插件是什么」转为「为什么值得进精选」（主人策展视角），重叠归属按 装机必备 > 崔添翼精选 > 自研 > 腾讯轻量云 优先级归桶，跨桶出处可用 tags 保留（如 better-sidebar 的「崔添翼精选」tag）。功能五分类退役，旧值仍可作社区开放 slug 命中自定义源；「精选区固定分类法（封闭集）」的机制不变，变的只是集合内容。
